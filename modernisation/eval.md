# Evaluation

Il vous a été demandé [ici](./localdev.md) de configurer l'environnement de développement pour votre équipe, en utilisant le projet [My-Invoice](https://dev.glassworks.tech/courses/fullstack/my-invoice) existant.

Certaines contraintes s'appliquent :

- Vous devez utiliser VSCode
- Vous devez utiliser Docker Dev Containers
- Vous devez installer un Linter et résoudre les problèmes
- Vous devez créer un projet central pour votre équipe sur GitLab

Une fois toutes ces étapes terminées, vous pouvez vous présenter à l'intervenant pour recevoir votre note :

| Element |  Note |
| -- | -- |
| L'API My-Invoice peut être exécutée sur tous les ordinateurs de l'équipe. | 5 |
| Un appel Postman vers l'API (qui invoque la base de données locale) fonctionne correctement. | 2 |
| Un linter est installé et toutes les erreurs sont corrigées. | 3 |
|  - Installation et configuration correctes | 1 |
|  - script dans la chaîne de compilation | 1 |
| Le projet est accessible sur GitLab, et tous les membres de l'équipe y ont accès. | 4 |
| L'équipe peut expliquer les politiques de gestion des branches (GitFlow) dans GitLab.  | 4 |
